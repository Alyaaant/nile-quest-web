# NILE QUEST v1.4: Language & Theme

- Header buttons: **EN / 日本語** toggles Japanese and English immediately.
- Moon / sun button toggles light / dark.
- Both preferences are persisted in browser localStorage.
- Gameplay progress is not reset when the display language changes.
- Quizzes have translated prompts, all four choices and explanations for each of the 15 questions.
- Scoring, authentication and SQLite remain server-authoritative.
- API answers are not translated by LLM; translations are curated in `src/game-en.mjs`.
- Note: Certain proper nouns (brand NILE QUEST, XP, country flags) remain unchanged.
